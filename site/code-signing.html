Code signing policy

Arcas.exe is not code-signed, so Windows may warn you when you download or open it. Arcas applied to the SignPath Foundation's free signing program for open-source projects and was declined on 3 November 2026: that program asks for public visibility, such as stars, forks and write-ups elsewhere, which a project one month old does not have. It was not a judgment on the code. Signing means buying a certificate, which has not been done.

Status
Declined by the SignPath Foundation on 3 November 2026, for too little public visibility, not for the code. Arcas may apply again once more people know it.
What would change it
A code signing certificate, which costs money and checks a real person's identity. The ones that fit an open-source project like this one are Certum's Open Source Code Signing and Microsoft's Azure Artifact Signing. Until one is bought every release stays unsigned, and the release notes tell you how to open it.
What gets signed
Only Arcas.exe as built by this repository's GitHub Actions workflow (build-exe.yml) from the public source code, after its tests pass, including the install on a fresh Windows PC. Nothing built anywhere else, and no other project's files.
